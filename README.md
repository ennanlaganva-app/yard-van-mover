# Yard Van Mover

A separate, free app for locating and shifting container vans in the yard. It uses step-by-step buttons for source bay and block, van selection, and destination bay and block. It has its own Android app name and yellow forklift icon. The original Container Van Locator remains available at the site root.

## Install on Android

Open <https://ennanlaganva-app.github.io/yard-van-mover/> in Chrome on Android. Tap **⋮** and choose **Install app** or **Add to Home screen**. Look for **Yard Van Mover** with the yellow forklift icon. This is an installable web app and does not require a paid service or a separate APK.

If an older shortcut called **Container Van Locator · Quick Move** is already on the phone, remove that older shortcut first. It may retain the old name and icon. Then open the Yard Van Mover link in Chrome and install the app with its new identity.

## Data

Both apps use the same browser storage on the same device, so saved yard records are available in either edition on that device. Records remain local to that browser. **Share snapshot** sends a point-in-time copy; it is not live syncing.
