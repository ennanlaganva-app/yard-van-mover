# Yard Van Mover

A separate, free app for locating and shifting container vans in the yard. Finder searches van IDs, shows status and a highlighted stack location, and opens picking tags. Quick Move uses step-by-step buttons for the source, van, destination bay/block, and exact destination stack position. Bays D and E show their paired front/back faces with a small separation between blocks. It has its own Android app name and yellow forklift icon. The original Container Van Locator remains available at its own site.

## Install on Android

Open <https://ennanlaganva-app.github.io/yard-van-mover/> in Chrome on Android. Tap **⋮** and choose **Install app** or **Add to Home screen**. Look for **Yard Van Mover** with the yellow forklift icon. This is an installable web app and does not require a paid service or a separate APK.

If an older shortcut called **Container Van Locator · Quick Move** is already on the phone, remove that older shortcut first. It may retain the old name and icon. Then open the Yard Van Mover link in Chrome and install the app with its new identity.

## Data

Both apps use the same browser storage on the same device, so saved yard records are available in either edition on that device. Records remain local to that browser. **Share snapshot** sends a point-in-time copy; it is not live syncing.

On **Add vans**, any non-empty van number or identifier can be entered as-is. The app does not require a particular format or ISO check digit. A bay, block, and open stack position are still required to save it to the yard.

## Yard capacities

- Bays A, B, and C: 4 / 4 / 4 / 3 positions per block (15 total).
- Bay D Front: 4 / 4; Bay D Back: 4 / 4 / 4.
- Bay E Front and Back: 4 / 4 / 4.

When changing a van’s location, choose its bay/side, block, stack, and level. The app does not silently place moved vans in a different open spot. Position numbers begin at the rear-bottom space and count upward stack by stack toward the front, skipping empty spots.

## Finder

Use the **Finder** page to search by van ID. The on-screen number pad sits on the right; the letter pad uses a QWERTY layout. Choose a result to see its consignee, status and timestamp, vessel/voyage, location, picking tag, and stack illustration. The selected van is highlighted in the result list and stack illustration. If no record exists, choose **Add van** to open the manual entry page with the searched ID filled in. An assigned van can be moved by selecting its highlighted stack tile, choosing a new exact position, or using Quick Move.
